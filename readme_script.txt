--------------------------------Содержание--------------------------------

- auxiliary_functions.py
- calculation_wells.py
- design.py
- dictionaries.py
- FirstRowWells.py
- geometry.py
- main.py
- mapping.py
- preparing_data.py
- print_in_excel.py
- regular_mesh_all_wells.py
- regular_mesh_intersections.py

--------------------------------Инструкция--------------------------------

--- auxiliary_functions.py
	Содержит вспомогательные функции для расчета такие как: распаковка словаря со статусами скважин (подготовка данных),
    	функция расчета времени исследования скважины, подготовка словаря по ключам для записи результатов и т.д.

--- calculation_wells.py
	Содержит основную функция расчета и функции для расчета первого сценария с приоритетом охвата добывающего фонда
    	пьезометрическими и нагнетательными скважинами

--- design.py
	Начало написания базового интерфейса

--- dictionaries.py
	Содержит словари для переименования столбцов датафреймов входных данных

--- FirstRowWells.py
	Скрипт для определения среднего радиуса первого окружения каждой скважины/объекта и мнимального радиуса первого ряда
	окружения для каждой скважины

--- geometry.py
	Все функции, связанные с пересечением/охватом зонами исследования скважин. Также скрипт сожержит функцию оптимизации
	пересечений первого сценария расчета с приоритетом охвата всего добывающего фонда и функцию загрузки контура
	пользователя по координатам из txt файла.

--- main.py
	Основной скрипт модуля. Содержит вызовы всех функций расчета, а также функций визуализации и запсии в Excel файл.

--- mapping.py
	Функции для визуализации результатов расчета. В зависимости от сценария расчета есть 2 функции построения картинок.

--- preparing_data.py
	Скрипт подготовки данных. Содержит нлавную функцию загрузки и подготовки данных. Внутри нее в зависимости от сценария
	выбирается название вспомогательной функции подготовки для определенного типа выгрузки. Также скрипт сожержит функцию
	загрузки исключаемых скважин и функцию подготовки .json файла с PVT-свойствами месторождений.

--- print_in_excel.py
	Содержит функции записи в Excel файл в зависимости от сценария расчета, а также функцию подготовки свобдной таблицы
	для первого сценария расчета.

--- regular_mesh_all_wells.py
	Расчет регулярной сетки скважин отдельно по фондам методом проходки по каждой скважине, начиная от самой нижней по
	координате Y.

--- regular_mesh_intersections.py
	Скрипт, содержащий функцию построения регулярной сетки всех фондов с учетом их порядка, указанного пользователем.
	Регулярная сетка строится на основе кол-ва охваченнных радиусом исследования скважин.
