--- main.py
	Основной скрипт модуля. Содержит вызовы всех функций расчета, а также функций визуализации и запсии в Excel файл.

	1) Вызывается функция загрузки параметров расчета upload_parameters(path) из скрипта auxiliary_functions.py
	2) Вызов функции подготовки DataFrame для расчета upload_input_data(dict_constant, dict_parameters) из скрипта
	   preparing_data.py
	3) Если после загрузки параметров расчета, указанных пользователем (пункт 1), дата, указаны: дата, начиная с которой
	   будет производиться учет ГДИС, и путь к файлу с данными по ГДИС, то вызывается функция подготовки и учета данных
	   ГДИС. Скважины, на которых ГДИС проводились с указанной пользователем даты
	4) Независимо от предыдущих пунктов производится чтение файла с PVT-свойствами по всем месторождениям и подготовка
	   для удобства дальнейшего использования в расчете с помощью функции preparing_reservoir_properties(dict_parameters, path)
	   из скрипта preparing_data.py
	5) Далее производится проверка на наличие контуров в указанной папке:
		а) если контуры есть, то выделяются скважины в контуре посредством функции
		   check_intersection_area(area, df_points, percent, calc_option), затем идет
		   расчет по одному из сценариев с помощью вызова функции 
		   calculation(polygon, df_in_contour, contour_name, path_property, list_exception, dict_parameters) из
		   скрипта calculation_wells.py
		б) если контуров нет, модуль сразу приступает к расчету скважин вне контуров с помощью вызова той же
		   функции calculation(polygon, df_in_contour, contour_name, path_property, list_exception, dict_parameters)
	6) В зависимости от выбранного сценария вызывается та или иная функция визуализации и одна из двух функций
	   записи результатов расчета в файл excel:
	   visualization(df_input_prod, percent, dict_result) либо mesh_visualization(df_input, dict_mesh, percent) из 
	   скрипта mapping.py для визуализации и write_to_excel(percent, df_input, dict_result, **dict_constant) либо 
	   write_cluster_mesh(df_input, dict_result, percent) из скрипта print_in_excel.py

--- auxiliary_functions.py
	Содержит вспомогательные функции для расчета такие как:

	- def unpack_status(dict_constant):

    		Распаковка параметров из словаря, для удобства использования в коде
    		dict_constant: словарь со статусами скважин и характером их работы
    		возвращает статусы и характер работы скважин как отдельные переменные типа string

	- get_time_research(path, df_result, horizon):

    		Добавление в результирующий DataFrame столбца со временем исследования, при условии,
    		что дебит у скважины не 0
    		path: путь к yaml-файлу с параметрами
    		df_result: DataFrame рассчитанный для контура
    		horizon: имя контура
    		возвращает DataFrame с добавленным столбцом времени исследования
	
	- get_property(path):

    		Считывание параметров из yaml-файла в словарь
    		path: путь к файлу с параметрами
    		возвращает словарь с параметрами по ключу объекта

	- wc_func(x, water_cut, const, S_o_init, S_w_init, Corey_w, Corey_o):

    		Функция зависимости обводненности от водонасыщенности
    		x: начальное приближение для поиска корня уравнения
    		water_cut: обводненность
    		const: коэффициент перед функцией (начальная водонасыщенность, остаточная нефтенасыщенность, вязкости, проницаемости)
    		S_o_init: остаточная нефтенасыщенность
    		S_w_init: начальная водонасыщенность
    		Corey_w: степень Кори для воды
    		Corey_o: степень Кори для нефти
    		возвращает значение функции обводненности

	- get_time_coef(dict_property, objects, Wc, oilfield, gas_status):

    		Рассчет коэффициента для формулы по вычислению времени исследования скважины
    		При умножении этого коэффицента на радиус охвата, получаем время исследования
    		gas_status: тип скважины для выбора формулы расчета времени КВД (нефтяная, газовая, газоконденсатная,
     		 водонагнетательная, газонагнетательная, поглощающая, пьезометрическая)
    		oilfield: название месторождения
    		Wc: обводненность
    		objects: название пласта
    		dict_property: словарь со свойствами всех пластов
    		возвращает коэффициент для расчета времени исследования

	- dict_keys(list_r, contour_name):

		Подготовка словаря по имени контура и списка коэффициентов увеличения радиуса
    		list_r: список коэффициентов для умножения радиуса
    		contour_name: имя контура
    		возвращает словарь с ключами из коэффициентов и имени текущего контура

	- upload_parameters(path):

    		Функция загрузки заданных пользователем параметров
    		path: путь к файлу с параметрами расчета
    		возваращает словарь с параметрами расчета

	- get_path():

		Функция возвращает путь, по которому находится exe файл

	- clean_work_horizon(df, count_of_hor):

    		Удаляет из DataFrame скважины с числом объектов работы больше заданного пользователем
    		df: база данных
    		count_of_hor: максимальное кол-во объектов работы скважины, задается пользователем
    		возвращает DataFrame со скважинами, число объектов работы которых не превышает заданного пользователем кол-ва

	- exception_marker(list_exception, wellName, fond):

    		Функция очистки пьезометрических и нагнетательных скважин из списка исключений
    		list_exception: список исключений
    		wellName: имя скважины
   		fond: фонд, к которому относится скважина
    		возращает либо имя скважины, либо пустую строку ''

--- preparing_data.py
	Скрипт подготовки данных. Содержит нлавную функцию загрузки и подготовки данных. Внутри нее в зависимости от сценария
	выбирается название вспомогательной функции подготовки для определенного типа выгрузки. Также скрипт сожержит функцию
	загрузки исключаемых скважин и функцию подготовки .json файла с PVT-свойствами месторождений.

	- upload_input_data(dict_constant, dict_parameters):

    		Считывание файла с исключенными скважинами, затем загрузка данных,
    		их подготовка к расчету в зависимости от базы данных
   		и удаление исключенных скважин
    		dict_constant: словарь со статусами работы скважин
		dict_parameters: словарь с параметрами расчета
   		Возвращается подготовленный DataFrame после считывания исходного файла со скважинами

	- preprocessing_GeoBD(df_input, dict_constant, dict_geobd_columns):

    		Подготовка данных ГеоБД
 		df_input: Выгрузка данных ГеоБД
		dict_constant: статусы и характеры работы скважин
		dict_geobd_columns: список имен столбцов
   		Возвращает DataFrame с необходимыми столбцами для расчета, столбцы в правильном порядке,
    		скважины разделены на ННС и ГС

	- preprocessing_NGT(df_input, min_length_horWell):

  		Подготовка данных из NGT
   		min_length_horWell: минимальная длина ГС, для разделения скважин на ННС и ГС
   		df_input: Выгрузка данных NGT
    		Возвращается подготовленный DataFrame выгрузки NGT, скважины разделены на ННС и ГС

	- upload_gdis_data(df_input, date, dict_parameters):

    		Загрузка данных по проведенным ГДИС на месторождении и удаление из входных данных
    		скважин, на которых проводились исследования начиная с введенной пользователем даты по сей день
		df_input: DataFrame, полученный путем считывания исходного файла со скважинами
		date: дата выгрузки файла со скважинами
		dict_parameters: словарь с параметрами расчета
		Возвращается DataFrame очищенный от скважин, на которых проводились ГДИС не более n лет назад

	- preparing(dict_constant, df_input, count_of_hor, watercut, fluid_rate, list_exception):

    		Подготовка к расчету DataFrame, прошедшего предварительную подготовку в зависимости от типа выгрузки
		fluid_rate: ограничение по дебиту жидкости
		dict_constant: словарь со статусами работы скважин
		watercut: ограничение на обводненность
   		list_exception: список имен исключаемых скважин
  		count_of_hor: кол-во объектов, заданное пользователем
   		df_input: DataFrame, полученный из входного файла
 		Возвращается DataFrame, подготовленный к расчету

	- gdis_preparing(df_gdis, input_wells, year):

    		Функция очищает загруженные данные ГДИС от скважин, на которых
    		ГДИС проводились раньше указанной пользователем даты
		df_gdis: данные ГДИС из файла с исследованиями по скважинам, считанные в DataFrame
		input_wells: имена всех скважин, входящих в исходный файл со скважинами
		year: опция расчета, задается в формате ДД/ММ/ГГГГ
  		Возвращает DataFrame со скважинами, на которых ГДИС проводились более n(year) лет назад

	- drop_wells_by_gdis(input_row, gdis_objects):

    		Функция удаляет объекты для каждой скважины, если по ним проводились ГДИС
		input_row: текущая строка из входного DataFrame
		gdis_objects: Series из объектов на которых проводились ГДИС, индексами я вляются скважины
		Возвращает измененную строку DataFrame или ту же строку, если скважины не оказалось в gdis_object Series

	- preparing_reservoir_properties(dict_parameters, path):

    		Подготовка PVT свойств из справочника PVT и далее запись в .json файл
    		для быстрого дотсупа к свойствам объектов в процессе расчета
    		dict_parameters: словарь с параметрами расчета
 		path: путь к корневой папке
		Сохраняет словарь в корневую папку в виде json файла со свойствами месторождений

	- get_exception_wells(dict_parameters):

    		Загрузка скважин для исключения из расчета
		dict_parameters: словарь с параметрами расчета
		Возвращает список скважин для исключения

--- calculation_wells.py
	Содержит основную функция расчета и функции для расчета первого сценария с приоритетом охвата добывающего фонда
    	пьезометрическими и нагнетательными скважинами:

	- calculation(polygon, df_in_contour, contour_name, path_property, list_exception, dict_parameters):

    		Основная функция расчета
    		polygon: контур, заданный пользователем
    		df_in_contour: DataFrame из скважин, находящихся внутри контура
  		contour_name: имя контура
   		path_property: путь к справочнику с PVT свойствами
   		list_exception: список исключаемых скважин
   		dict_parameters: словарь с параметрами расчета
    		Возвращает словарь с результирующим DataFrame по каждому ключу

	- piez_calc(df_piez_wells, hor_prod_wells, df_result, percent):

    		Функция обрабатывает DataFrame из пьезометров, подающийся на вход
   		percent: процент длины траектории скважины для включения в зону охвата
    		df_piez_wells: DataFrame из пьезометров, выделенный из входного файла
    		hor_prod_wells: DataFrame из добывающих скважин
    		df_result: В функцию подается DataFrame df_result для добавления в общий результат расчета пьезометров
    		Возвращаются: 	1) список скважин, не имеющих пересечений;
                          	2) DataFrame пьезометров;
                           	3) DataFrame добывающих;
                           	4) Общий DataFrame со всеми результатами расчета по объекту

	- inj_calc(isolated_wells, hor_prod_wells, df_inj_wells, df_result, percent):

    		Функция обарабатывает DataFrame нагнетательных скважин
    		percent: процент длины траектории скважины для включения в зону охвата
    		isolated_wells: Список скважин, не имеюших пересечений
    		hor_prod_wells: DataFrame добывающих скважин
    		df_inj_wells: DataFrame нагнетательных скважин
    		df_result: Результирующий DataFrame, к которому добавится результат обработки DataFrame нагнетательных скв.
    		Возвращаются: 	1) список скважин, не имеющих пересечений;
                           	2) DataFrame нагнетательных;
                           	3) DataFrame добывающих;
                           	4) Общий DataFrame со всеми результатами расчета по объекту

	- single_calc(list_exception, isolated_wells, hor_prod_wells, df_result, percent):

    		Функция обарабатывает DataFrame одиночных скважин
    		list_exception: список исключаемых из расчета скважин
    		percent: процент длины траектории скважины для включения в зону охвата
		isolated_wells: Список скважин, не имеюших пересечений
 		hor_prod_wells: DataFrame добывающих скважин
   		df_result: Результирующий DataFrame, к которому добавится результат обработки DataFrame одиночных скв.
    		Возвращаются: 	1) список скважин, не имеющих пересечений;
                           	2) DataFrame добывающих;
                           	3) Общий DataFrame со всеми результатами расчета по объекту

	- calc_contour(df_prod_wells, df_piez_wells, df_inj_wells, df_result, horizon, mean_rad, coeff, key,
                 obj_square, path_property, list_exception, dict_parameters):

    		Функция расчета оптимальной опорной сетки, включающая в себя все функции обработки отдельных типов скважин
    		obj_square: площадь объекта по крайним скважинам с отступом на средний радиус исследования
    		key: результирующего ключ словаря
    		coeff: коэффиуиент кратного увеличения радиуса
		mean_rad: средний радиус первого ряда окружения по объекту
		horizon: текущий объект расчета
		df_result: результирующий DataFrame
		df_inj_wells: DataFrame нагнетательных скважин
		df_piez_wells: DataFrame пьезометрических скважин
   		df_prod_wells: DataFrame добывающих скважин
		dict_parameters: словарь с параметрами (коэффициенты на радиус, углы перекрытия и тд)
    		list_exception: список исключаемых из расчета скважин
    		 "слепых" зон и скважин в них
 		path_property: путь к файлу с параметрами
    		средним радиусом в этом случае для построения области взаимодействия будет заданное максимальное расстояние
 		Возвращается словарь с добавленным ключом по коэффициенту умножения радиуса охвата

	- calc_horizon(list_prod_exception, path_property, percent, mean_rad, coeff, horizon,
                 obj_square, min_time_research, max_time_research, df_piez_wells, df_prod_wells, df_inj_wells,
                 df_result):

    		Функция для расчета результирующего DataFrame по объекту для оптимальной ОС
    		max_time_research: ограничение максимального времени исследования ННС
    		min_time_research: ограничение минимального времени исследования ННС
    		obj_square: площадь объекта месторождения по краевым скважинам
  		list_prod_exception: список исключаемых из расчета скважин
    		path_property: путь к файлу со свойствами
  		percent: процент длины траектории скважины для включения в зону охвата
   		mean_rad: средний радиус по объекту
   		coeff: коэффициент кратного увеличения радиуса
    		horizon: объект, по которому идет расчет
   		df_piez_wells: пьезометры по текущему объекту
   		df_prod_wells: добывающие скважины по текущему объекту
    		df_inj_wells: нагнетательные скважины по текущему объекту
  		df_result: пустой DataFrame, в который записывается результат расчета
    		Возвращает результирующий DataFrame по объекту с оптимальной ОС

	- get_invisible_wells(df_recalc, df_prod, percent, radius, coeff):

    		Функция получения скважин в слепой зоне при k > 1.5 (k*R)
   		coeff: коэффициент домножения радиуса
 		df_recalc: копия результирующего DataFrame для выделения скважин в слепой зоне
 		df_prod: DataFrame добывающих скважин
  		percent: процент перекрытия зоной охвата, при котором скважина попадает в нее
		radius: максимальный радиус охвата в слепой зоне
   		Возвращает список скважин для дообследования и DataFrame с обновленным столбцом пересечений

	- separation_gdis(df_invisible):

    		Функция разделения скважин в слепых зонах на 2 года
   		df_invisible: DataFrame скважин, которые попали в слепую зону
		Возвращает два DataFrame, по которым распределены скважины в слепой зоне(каждая вторая)

--- regular_mesh_intersections.py
	Скрипт, содержащий функцию построения регулярной сетки всех фондов с учетом их порядка, указанного пользователем.
	Регулярная сетка строится на основе кол-ва охваченнных радиусом исследования скважин.

	- calc_regular_mesh(df_prod_wells, df_piez_wells, df_inj_wells, df_result, horizon,
                      path_property, dict_parameters, obj_square, mean_rad, coeff):

    		Расчет регулярной сетки скважин
		df_prod_wells: DataFrame добывающих скважин на текущий объект расчета
		df_piez_wells: DataFrame пьезометрических скважин на текущий объект расчета
		df_inj_wells: DataFrame нагнетательных скважин на текущий объект расчета
 		df_result: результирующий DataFrame содержащий опорные скважины
   		horizon: текущий объект расчета
  		path_property: путь к файлу с PVT свойствами
   		dict_parameters: словарь с параметрами расчета
		obj_square: площадь текущего объекта расчетп по крайним скважиам
    		mean_rad: средний радиус исследования по текущему объекта
   		coeff: коэффициент кратного увеличения радиуса исследования
    		Возвращается результирующий DataFrame с опорными скважинами

--- FirstRowWells.py
	Скрипт для определения среднего радиуса первого окружения каждой скважины/объекта и минимального радиуса первого ряда
	окружения для каждой скважины

	- check_well_intersection(df_intersectionWells, MaxOverlapPercent):

    		Проверка пересечений между скважинами в исходном массиве, для исключения перекрываемых скважин второго ряда
   		df_intersectionWells: массив скважин с исходными данными
    		MaxOverlapPercent: максимальный процент от общей длины ствола скважины, который может быть скрыт при
                             	   пересечении, чтобы скважина осталась в первом ряду
    		Возвращает список скважин за первым рядом, которые требуется удалить

	- first_row_of_well_geometry(df_WellOneArea, wellNumberInj,
                               verticalWellAngle, MaxOverlapPercent,
                               angle_horizontalT1, angle_horizontalT3):

    		Поиск для нагнетательной скважины окружения первого ряда на основе геометрии
   		angle_horizontalT3: sector expansion angle for horizontal well's T1 point
    		angle_horizontalT1: sector expansion angle for horizontal well's T3 point
   		df_WellOneArea: массив скважин окружения с расстоянием до нагнетательной < maximumDistance
    		wellNumberInj: номер рассматриваемой нагнетательной скважины
    		verticalWellAngle: угол для обозначения зоны вертикальных скважин на карте
   		MaxOverlapPercent: максимальный процент от общей длины ствола скважины, который может быть скрыт при
                                   пересечении, чтобы скважина осталась в первом ряду
    		Возвращает список скважин первого ряда

	- mean_radius(df_in_contour, verticalWellAngle, MaxOverlapPercent,
                angle_horizontalT1, angle_horizontalT3, max_distance):

    		Расчет среднего и минимального радиусов первого ряда окружения по объекту
 		df_in_contour: DataFrame скважин, попавших в контур
  		verticalWellAngle: угол расширения сектора вертикальных скважин в полярной системе координат
   		MaxOverlapPercent: максимальный процент перекрытия от общей длины скважины
   		angle_horizontalT1: угол расширения сектора T1 ГС в полярной системе координат
    		angle_horizontalT3: угол расширения сектора T3 ГС в полярной системе координат
    		max_distance: максимальный радиус для выделения скважин первого окружения
   		Возвращает средний радиус по объекту и DataFrame с добавленными столбцами минимального расстояния
		первого окружения для каждой скважины и средним радиусом для всех скважин текущего объекта расчета

--- geometry.py
	Все функции, связанные с пересечением/охватом зонами исследования скважин. Также скрипт содержит функцию оптимизации
	пересечений первого сценария расчета с приоритетом охвата всего добывающего фонда и функцию загрузки контура
	пользователя по координатам из txt файла

	- get_polygon_well(R_well, type_well, *coordinates):

    		Создание зоны вокруг скважины с заданным радиусом
   		R_well: радиус создания зоны
    		type_well: тип скважины
    		coordinates: координаты устье/забой
   		Возвращает геометрический объект зоны вокруг скважины

	- check_intersection_area(area, df_points, percent, calc_option):

    		Проверка входят ли скважины из df_point в зону другой скважины area
   		percent: процент попадания скважины в зону охвата area
		calc_option: флаг переключения сценария охвата скважин
   		area: координаты зоны вокруг конкретной скважины
   		df_points: данные из которых берется геометрия скважин(точки/линии)
   		Возвращаются имена скважин, которые входят в данную зону area

	- check_intersection_point(point, df_areas, percent, calc_option):

    		Функция позволяет узнать, перечесение со сколькими зонами имеет определенная скважина
   		calc_option: флаг переключения сценария охвата скважин
   		percent: процент попадания скважины в зону охвата
    		point: геометрия скважины(точка/линия)
    		df_areas: DataFrame со столбцом зон вокруг скважин
    		Возщвращает перечесение со сколькими зонами имеет определенная скважина

	- intersect_number(df_prod, df_inj_piez, percent):

    		Функция добавляет в DataFrame столбец 'intersection', в него записываются
    		имена скважин из другого DataFrame, с которыми пересекается текущая, затем добавляется столбец 'number',
    		в который заносится кол-во пересечений конкретной скважины с остальными
  		percent: процент попадания скважины в зону охвата
  		df_prod: добывающие
   		df_inj_piez: нагнетательные/пьезометры
    		Возвращаются DataFrame с кол-вом пересечений

	- optimization(df_prod, df_inj_piez):

    		Выделяется список нагнетательных/пьезометров из DataFrame продуктивных,
    		имеющих 1 пересечение. Оптимизация заключается в переопределении
    		списка нагн/пьез. с помощью исключения скважин, входящих
    		как в список пересечений, так и в список исключений, из df_optim
    		df_prod: DataFrame добывающих скважин
    		df_inj_piez: DataFrame нагнетательных/пьезометров
  		Возвращает обновленный список нагнетательных/пьезометров

	- add_shapely_types(df_input, mean_rad, coeff):

    		Добавление в DataFrame столбца с площадью охвата скважин, в зависимости от среднего радиуса охвата по контуру
   		coeff: коэффициент домножения радиуса
    		df_input: DataFrame, полученный из исходного файла
    		mean_rad: средний радиус окружения для итерируемого объекта
    		Возвращается DataFrame с добавленными столбцами геометрии и площади влияния каждой скважины

	- load_contour(contour_path):

    		Загрузка файла с координатами контура и построение многоугольника
   		contour_path: Путь к файлу с координатами контура
   		Возвращается многоугольник GeoPandas на основе координат из файла
