
------------------------------Содержание корневой папки------------------------------

_internal | папка с необходимыми библиотеками python для работы приложения

input | папка с исходными файлами (выгрузки, контуры: txt-файлы с координатами контуров)

output | папка для сохранения результатов расчета

Icon.ico | файл иконки приложения

README.txt | краткая инструкция пользователя

wellnet_default.db | база данных для загрузки рассчитанных результатов при запуске программы

Методичка ОС.docx | полное руководство пользователя

Модуль ОС.exe | файл для запуска приложения


-------------------------------------------------------------------------------------

-----------------------------------Инструкция----------------------------------------

1) Подготовить исходный файл формата ".xlsx" с данными по скважинам месторождения.
   Разделителем разряда чисел должна быть точка.
   Можно использовать выгрузку из NGT Smart версии 5.8.2, либо из ГеоБД ArcGIS.
   Названия имен скважин должно быть одинаковым во всех загрузочных файлах.

   --- Для выгрузки из NGT Smart важен порядок столбцов:
		№ скважины
		Дата
		Характер работы
		Состояние
		Месторождение
		Объекты работы
		Куст
		Координата X
		Координата Y
		Координата забоя Х (по траектории)
		Координата забоя Y (по траектории)
		Дебит нефти (ТР), т/сут
		Дебит жидкости (ТР), м3/сут
		Приемистость (ТР), м3/сут
		Обводненность (ТР), % (объём)
		Способ эксплуатации
		Дебит природного газа, тыс.м3/сут
		Приемистость (по суточным), м3/сут
		Дебит конденсата газа, т/сут

   --- Для выгрузки ArcGIS ГеоБД выгружаются все столбцы вместе с точками Т3 скважин.

   --- При необходимости учета уже выполненных исследований требуется
   подготовить выгрузку с историей ГДИС из той же базы данных, что и основная выгрузка.

   Выгрузка ГДИС из NGT Smart не требует дополнительной подготовки. Можно вставить на
   лист с именем "ГДИС" таблицу.

   Выгрузка ГДИС из ГеоБД требует специальной вставки на лист ГДИС. Так как алгоритм подготовки
   данных при распределении исследований на достоверное/недостоверное будет ориентироваться на
   цвет значений столбца "Рпл  на ВНК, кгс/см2":

		красный цвет - высокое качество исследования
		зеленый цвет - среднее качество исследования
		черный цвет - низкое качество исследования
		синий цвет - повторяющиеся значения

   При обычном копировании таблицы в Excel цвета таблицы могут поменяться, поэтому для выгрузки ГДИС 
   ГеоБД необходимо использовать специальную вставку при копировании таблицы. В противном случае алгоритм
   обработки данных может отнести всю таблицу к низкому качеству исследования.

   Данные по ГДИС расположить в файле формата .xlsx на листе с названием "ГДИС"

   --- Для исключения скважин из расчета необходимо разместить имена этих скважин на листе "Исключения"
   в первом столбце (столбец "A" в Excel). Указанные скважины будут исключены из расчета.

	Пример:

		      A     |      B      |      C      |     D     
		 ----------------------------------------------------
		 скважина 1 |	   	  |	        |	    
		 ----------------------------------------------------
	    	 скважина 2 |		  |	        |	    
		 ----------------------------------------------------
	    	 скважина 3 |		  |	        |	    

   --- Учет проектных скважин производится размещением на листе "Проектный фонд" таблицы вида:
	

		    NSKV    |      X      |      Y      |   PLAST   
		-----------------------------------------------------
		      t     |	   0	  |	 0	|     t	    
		-----------------------------------------------------
		 скважина 1 |	   1	  |	 1	|  пласт 1  
		-----------------------------------------------------
		 скважина 2 |	   2	  |	 2	|  пласт 2  
	
	где NSKV - название скважины, X - координата по оси X, Y - координата по оси Y, PLAST - объекты проектной скважины


   --- Скорректировать попадание какой-либо отдельной или нескольких скважин в программу ГДИС по всем объектам ее работы,
   необходимо аналогично листу "Исключения" добавить обязательные для исследования скважины в первый столбец листа "Приоритетные скважины".
	
	Пример:

		      A     |      B      |      C      |     D     
		 ----------------------------------------------------
		 скважина 1 |	   	  |	        |	    
		 ----------------------------------------------------
	    	 скважина 2 |		  |	        |	    
		 ----------------------------------------------------
	    	 скважина 3 |		  |	        |	

   *Также есть возможность расчета опорной сети в пределах выделенных пользователем зон. 
   Для этого требуется подготовить выгрузку отрисованных контуров из NGT Smart 
   в ".txt" формате и поместить их в папку input.

2) Заполнить необходимые параметры расчета в главном окне приложения.

	--- Файл с данными - абсолютный путь к файлу с данными для расчета
	    Пример: C:\Users\USER\ well_net\input\Фонд.xlsx

	--- Опции расчета:
		
		-> Сценарий расчета - выбор алгоритма построения сетки (оптимальная или регулярная).
		   Значения выбираются из выпадающего списка: "Оптимальная сетка" / "Регулярная сетка"

		-> Дата последнего ГДИС - дата последнего актуального ГДИС. Задается в формате дд/мм/гггг. 			   			   Учитываются ГДИС, проведенные после указанной даты.
		   Пример: 01.01.2023

		-> Критерий охвата траектории ГС - вкл/выкл учета процента длины траектории, попавшей
		   в зону исследования. Значения выбираются из выпадающего списка: "Да" / "Нет".

		-> % охвата длины ГС для исследования - процент от длины от точки T1 до T3, необходимый, чтобы 			   			   исследование было достоверным. ННС сразу же попадают в зону охвата, так как являются точками
		   при расчете.
		   Пример: 70 (оптимальное значение)

		-> Максимальное кол-во объектов скважины - отбирает из данных скважины с заданными кол-вом объектов.
		   Для отключения данного фильтра можно указать 0 или оставить значение параметра пустым.
		   Пример: 1

	--- Основные параметры

		-> Список коэффициентов - список коэффициентов кратного увеличения оптимального радиуса исследования,
		   указанные через запятую.
		   Пример: 1, 1.5, 2, 2.5

		-> Ограничение коэффициента на R - граничное значение коэффициента кратного увеличения радиуса исследования,
		   при котором исследование считается достоверным
		   Пример: 1.5 (оптимальное значение)

		-> Минимальная длина ГС (для NGT Smart) - в выгрузке NGT нет признака разделения скважин на ННС и ГС,
		   в связи с этим, используется граничное значение расстояния между точками T1 и T3, чтобы отнести
		   скважину к определенному типу
		   Пример: 150

		-> Обводненность, % - значение, ниже которого добывающие нефтяные скважины исключаются из построения
		   программы ГДИС
		   Пример: Пример: 70 (скважины в добывающем фонде с обводненностью ниже 70% будут исключены)

		-> Дебит жидкости, м3/сут - значение, ниже которого добывающие нефтяные скважины исключаются
		   из построения программы ГДИС. Если значение не указано, ограничение не применяется.
		   Пример: 10

		-> Учет Q ср. по объекту - вкл/выкл учета добывающих нефтяных и газоконденсатных скважин
		   с дебитом нефти выше среднего по объекту при построении программы ГДИС. Значения выбираются
		   из выпадающего списка: "Да" / "Нет".

		-> % от Q ср. по объекту - процент от среднего дебита добывающих скважин по объекту для
		   параметра "Учет Q ср. по объекту"
		   Пример: 50

		-> Ограничение на дебит нефти, т/сут - значение, выше которого добывающие нефтяные скважины
		   исключаются из построения программы ГДИС оптимальной/регулярной сетки. Чтобы не учитывать
		   ограничение нужно оставить поле параметра пустым
		   Пример: 10

		-> Учет границ исследования ННС/ГС - вкл/выкл учет границ времени исследования для ННС/ГС
		   с параметрами "Минимальное время исследования ННС, сут" и "Максимальное время исследования ННС, сут".
		   Значения выбираются из выпадающего списка: "Да" / "Нет".

		-> Минимальное время исследования ННС, сут - значение для нижней границы времени исследования скважин. 
		   Если рассчитанное время исследования скважины меньше, то в таблице результатов у таких скважин будет
		   записано указанное число суток. Для ГС время умножается на 2. В случае, когда параметр не введен,
		   условие не будет применено в расчете
		   Пример: 5

		-> Максимальное время исследования ННС, сут - значение для нижней границы времени исследования скважин.
		   Если рассчитанное время исследования скважины больше, то в таблице результатов у таких скважин будет
		   записано указанное число суток. Для ГС время умножается на 2. В случае, когда параметр не введен,
		   условие не будет применено в расчете
		   Пример: 15

	--- Регулярная сетка

		-> Учет % от каждого фонда - вкл/выкл вхождения в равномерную сетку определенного % скважин от каждого фонда.
		   Значения выбираются из выпадающего списка: "Да" / "Нет".

		-> Порядок фондов для ГДИС - набор из слов "доб", "наг", "пьез" в произвольном порядке. Необходимо указать
		   их в порядке приоритетности построения равномерной сетки

		-> % пьезометрических скважин - процент от кол-ва пьезометрических скважин, которые необходимо включить в 
		     равномерную сетку

		-> % нагнетательных скважин - процент от кол-ва нагнетательных скважин, которые необходимо включить в 
		     равномерную сетку

		-> % добывающих скважин - процент от кол-ва добывающих скважин, которые необходимо включить в 
		     равномерную сетку

	--- Оптимальный охват добывающего фонда (учитывается при выборе сценария расчета "Оптимальная сетка")

		-> Распределение ГДИС скважин по годам - параметр определяет кол-во лет, на которые нужно
		   распределить скважины на повторное исследование. При большом радиусе исследования добывающие
		   скважины могут оказаться в "слепых зонах" (данные по их исследованию будут недостоверны).
		   Чтобы этого избежать, программа при заданном параметре будет распределять скважины для исследования
		   в таких зонах на 1 или 2 года вперед. Значение параметра выбираются из выпадающего списка: 0 / 1 / 2.
		   Если задано значение 0, распределения скважин по года на дополнительное исследование не будет.

	--- Первый ряд окружения

		-> Максимальный радиус, м - максимальный радиус для последующего выделения скважин первого окружения
		   Пример: 500

		-> Сектор для ННС в ПСК, градусы - угол выделения сектора для вертикальных скважин на карте
		   в полярной системе координат
		   Пример: 10

		-> Ограничение по % перекрытия - максимальный процент перекрытия от длины скважины в полярной системе координат.
		   Основной критерий для выделения скважин первого окружения
		   Пример: 20

		-> Сектор для T1 ГС в ПСК, градусы - угол выделения сектора для T1 горизонтальных скважин на карте
		   в полярной системе координат
		   Пример: 10

		-> Сектор для T3 ГС в ПСК, градусы - угол выделения сектора для T3 горизонтальных скважин на карте
		   в полярной системе координат
		   Пример: 10

3) Выбор пути сохранения базы данных с результатами. В левом нижнем углу главного окна есть редактируемая ячейка для
   ввода пути для сохранения базы данных с результатами расчета. По умолчанию указан путь сохранения в директорию расположения
   приложения в папку output

4) Для запуска расчета необходимо нажать кнопку "Рассчитать и сохранить" в левом нижнем углу главного окна

5) Окно логирования. После запуска расчета появляется маленькой окно с информацией о выполнении расчета и полосой прогресса.
   Главное окно на время расчета деактивируется. Оно снова станет активным после следующих действий:
		
	--- Дождаться завершения расчета
	
	--- Закрыть окно логирования. При этом действии расчет будет остановлен

	--- В правом нижнем углу окна логирования нажать кнопку "Прервать расчет"

6) В правой части главного окна отображаются результаты расчета. Между сценариями и объектами расчета можно переключаться
   с помощью выпадающих списков, расположенных в верхней правой части главного окна

	--- Сводка по результатам (сводная таблица по всем сценариям расчета). Вкладка содержит 2 кнопки:

		-> Сохранить все сценарии в Excel

		-> Сохранить все сценарии по текущему объекту

	--- Визуализация (картинка по выбранному сценарию и объекту расчета). На вкладке присутствуют
	    кнопки взаимодействия с картинкой

	--- Таблица опорной сетки (таблица опорной сетки по выбранному сценарию и объекту расчета)

7) Меню приложения включает 2 основных пункта:

	--- Файл:

		-> Загрузить... - при нажатии на кнопку открывается папка output в директории расположения приложения.
				  Выбрать можно только файл формата ".db", рассчитанные ранее в этом приложении

	--- Помощь:

		-> Краткая инструкция - при нажатии открывает краткую инструкцию по работе с приложением

		-> Руководство пользователя - при нажатии открывает руководство пользователя по приложению

8) Завершить работу приложения можно нажав крестик в правом верхнем углу главного окна
